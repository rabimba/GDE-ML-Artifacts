ADK - Agent Development Kit

A collection of Python scripts demonstrating a multi-agent system using the Agent Development Kit.

ADK Scripts

This directory contains the components of a multi-agent application. You can interact with it through a command-line interface or a Streamlit web application.

agents.py

Defines a variety of agents using the "Agent Development Kit" (ADK). These agents are specialized for tasks like generating day trip itineraries, finding food, guiding weekend events, and providing transportation directions. It also defines more complex agents like a SequentialAgent, LoopAgent, and ParallelAgent to create workflows.

cli.py

A command-line interface for interacting with the agents defined in agents.py. It takes a query and an API key as input, uses a "router" agent to select the appropriate specialist agent or workflow, and then executes the query.

core.py

Contains the core logic for running the agents. It includes functions for configuring the API key and executing a query with an agent. It also initializes the session service.

streamlit_app.py

A Streamlit web application that provides a user-friendly chat interface for interacting with the agents. It's an alternative to the command-line interface.
