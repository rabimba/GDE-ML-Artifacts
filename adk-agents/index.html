What is Google ADK?

Google's Agent Development Kit (ADK) is a comprehensive framework for building sophisticated multi-agent applications powered by Large Language Models. ADK enables developers to create scalable, modular AI systems with specialized agents working together seamlessly.

Agent Types in Google ADK

ADK provides different agent types to handle various use cases and execution patterns.

🧠

LLM Agent

Powered by LLMs like Gemini to understand natural language, reason, and make decisions

Question answering Content generation Data analysis Decision making
from google.adk.agents import LlmAgent agent = LlmAgent( name="assistant", model="gemini-2.5-flash", instruction="You are a helpful assistant", tools=[google_search] )

Workflow Agents

Orchestrate multiple agents with different execution patterns

➡️ Sequential Agent

Executes sub-agents one after another in a fixed order

Step-by-step pipelines Data processing workflows Multi-stage analysis

⚡ Parallel Agent

Executes multiple sub-agents concurrently for speed

Independent data fetching Simultaneous API calls Concurrent processing

🔄 Loop Agent

Iterative refinement Polling operations Retry logic

Communication Methods

Learn how agents communicate and share information.

📦 Shared State

Agents communicate through shared session state

How it works: One agent writes to state, another reads from it

# Agent 1 writes context.state['data'] = processed_data # Agent 2 reads data = context.state.get('data')

🔀 LLM-Driven Delegation

LLM decides which sub-agent to route to

How it works: Parent agent's LLM generates transfer_to_agent() call

Example Routing:

"Book a flight to Paris" → Flight Booking Agent
"My payment failed" → Billing Agent
"I can't log in" → Technical Support Agent

🔧 Agent as Tool

Agents wrapped as tools for parent agent

How it works: Parent calls AgentTool which executes sub-agent

Benefits:

Modular design Reusable components Clear interfaces
